# swag-labs-manual-testing

Manual Testing Project of Swag Labs E-commerce Website using Excel and Jira.

## Project Overview
This project is based on manual testing of the Swag Labs E-commerce website.

## Application Details
- Application: Swag Labs
- Website: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Test Case Tool: Microsoft Excel
- Bug Tracking Tool: Jira

## Modules Tested
1. Login
2. Products
3. Product Sorting
4. Add to Cart
5. Checkout Information
6. Checkout Overview
7. Checkout Complete
8. Logout and Navigation Menu

## Test Cases
Test cases are documented in an Excel workbook.

**Excel File:** SwagLabs_Manual_Test_Cases.xlsx
